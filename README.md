# Supermarket Management System

## About the Project

The Supermarket Management System is a database project developed as part of the Fourth Year, Second Semester coursework.

The main objective of this project is to manage supermarket operations efficiently through a computerized system. It provides role-based access for different users and helps manage products, supermarket branches, sales information, and reports.

This project was developed by a group of 6 members as part of our university database course.

## Project Information

- Project Name: Supermarket Management System
- Academic Year: Fourth Year
- Semester: Second Semester
- Course: Database
- Project Type: Group Project
- Group Members: 6

## Main Features

- User Authentication: Secure login for system users.
- Role-Based Access Control: Different dashboards for Global Admin, Local Admin, and Cashier.
- Product Management: Manage supermarket product information.
- User Management: Manage system users and their roles.
- Sales Reports: View and manage sales reports.
- System Settings: Manage system-wide settings.
- Branch Management: Support supermarket operations across multiple branches.

## User Roles

- Global Admin: Oversees the overall supermarket system.
- Local Admin: Manages operations at an assigned branch.
- Cashier: Handles cashier-related operations.

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- Eclipse IDE

## Project Team

This project was collaboratively developed by 6 group members for our Fourth Year, Second Semester Database course.

## Purpose

The purpose of this project is to apply database concepts and software development skills to a practical supermarket management scenario. It also provides hands-on experience in database connectivity, user interface development, and role-based system design.
